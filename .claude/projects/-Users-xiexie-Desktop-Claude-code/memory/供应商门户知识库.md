# 供应商门户知识库

## 一、系统概述

### 1.1 系统定位
供应商门户是连接供应商与企业内部的协同平台，实现商品管理、货品池运营、采购订单全生命周期管理，提升供应链协同效率。

### 1.2 关联系统
| 系统名称 | 交互内容 |
|---------|---------|
| 订单履约平台 | 采购单状态同步、需求单管理、内部商品需求管理 |
| 易仓ERP | 库存同步、入库通知、颜色/尺码库同步 |
| 商品运营平台 | 商品信息同步、库存更新、品类库接口 |
| Shopify独立站 | 动销订单数据获取 |
| SDP款式开发平台 | 图包同步、颜色/尺码字典、POD商品生产资料接口 |

## 二、角色与权限

### 2.1 用户角色
| 角色 | 权限范围 | 数据隔离 |
|-----|---------|---------|
| 供应商账号 | 商品管理、采购订单操作 | 仅查看归属自己的数据 |
| 内部账号(采购员) | 货品池选品、采购单管理、内部商品需求管理 | 可查看全部供应商数据 |
| 内部账号(审核员) | 审核流程处理 | 按审核类型分配权限 |
| 系统管理员 | 配置管理、权限控制 | 全部数据 |

### 2.2 核心权限规则
- 供应商只能操作归属自己的商品和订单
- 采购员可查看企业内所有采购单，无供应商/品类限制
- 预警配置仅管理员可操作
- 采购需求手动触发按钮：仅对企业内部测试人员、特殊业务负责人开放

## 三、商品管理模块

### 3.1 商品状态体系

#### 供应商维度状态
| 状态 | 说明 | 可操作 |
|-----|------|-------|
| 草稿 | 商品未推品 | 编辑、删除、推品 |
| 已推品 | 已推品至货品池 | 取消推品 |
| 待完善 | 信息不完整 | 编辑、取消推品 |
| 已选品 | 买手已选中 | 编辑(有限制)、取消推品 |
| 已选品-待审核 | 供应商修改待审核 | 查看日志 |
| 未选中 | 买手淘汰 | 重新选品 |
| 已取消推品 | 供应商撤回推品 | 查看日志 |

#### 内部货品池维度状态
| 状态 | 说明 |
|-----|------|
| 草稿 | 商品未推品 |
| 待选品 | 等待买手筛选 |
| 选品中 | 买手正在筛选 |
| 已选品 | 买手已选中 |
| 已选品-待审核 | 供应商修改待审核 |
| 未选中 | 买手淘汰 |
| 已取消推品 | 供应商撤回 |

### 3.2 商品操作规则

#### 编辑权限规则
| 商品状态 | 可编辑内容 |
|---------|-----------|
| 草稿/待完善 | 所有字段 |
| 已选品未同步 | 基础信息、商品属性、物流包装、SKU规则、商品图片(仅新增SKC图) |
| 已选品已同步 | 商品属性、SKU规则(新增/供货价/库存)、商品图片(仅新增SKC图) |

**注意**：已选品状态编辑后，状态变为"待审核"，审核通过后生效

#### 取消推品规则
| 状态 | 操作结果 |
|-----|---------|
| 已推品/待完善 | 状态变为草稿 |
| 已选品(未同步) | 审核通过后变为已取消推品 |
| 已选品(已同步) | 审核通过后变为已取消推品，调用商品运营下架API |

### 3.3 批量导入能力

| 导入类型 | 支持维度 | 核心步骤 |
|---------|---------|---------|
| 批量导入商品 | SPU/SKU | 选择维度→上传文件→数据预览→导入进度→导入结果 |
| 批量导入商品属性 | SPU | 选择品类→下载模板→上传文件→数据预览→确认导入 |
| 批量导入图片 | 主图/SKC图/尺码图/详情图 | 按命名规则上传→系统自动匹配 |
| 批量修改价格/库存 | 商品 | 库存为0时自动同步商品运营 |

### 3.4 品类选择规则

#### 品类层级与可修改性
| 层级 | 说明 | 供应商门户可修改性 | 订单履约平台可修改性 |
|-----|------|------------------|---------------------|
| 一级品类（大类） | 商品一级分类 | **商品创建后不可修改** | **商品创建后不可修改** |
| 二级品类 | 大类下的细分类别 | 草稿/待完善状态**可修改** | **可修改** |
| 末级品类 | 品类树的最细粒度分类 | 草稿/待完善状态**可修改** | **可修改** |

#### 品类修改后的属性处理
| 场景 | 处理规则 |
|-----|---------|
| 新品类有原品类不存在的属性 | 新增属性字段，编辑时显示为空，保存时按必填设置校验 |
| 原品类有新品类不存在的属性 | 删除该属性数据 |
| 两品类共有属性 | 保留原有属性值 |

## 四、商品属性动态化

### 4.1 属性类型说明
| 属性类型 | 维度 | 配置来源 | 是否使用快照 |
|---------|------|---------|-------------|
| 商品属性 | SPU | 末级品类配置 | ❌ 不使用，始终取最新 |
| 销售变体 | SKU | 一级品类配置 | ✅ 使用，创建时保存 |
| SKC图 | SKC | 一级品类配置 | ✅ 使用 |

### 4.2 配置快照机制
- **销售变体配置**：商品创建时保存配置快照，品类库变更不影响已创建商品
- **商品属性配置**：不使用快照，编辑时实时获取品类库最新配置
- **SKC生成依据**：存储在销售变体配置快照中

### 4.3 SKU属性拼接规则
- **拼接顺序**：SKC生成依据字段排在最前面，其他字段按配置顺序排列
- **分隔符**：使用 `/` 分隔各销售变体值
- **示例**：颜色=红色，尺码=M，SKC生成依据=颜色 → "红色/M"

### 4.4 SKC编号生成规则
| 规则项 | 说明 |
|-------|------|
| 编号格式 | SPU编码 + "-" + 2位递增序号（如 SP001-01） |
| 生成依据(方案A) | 品类库接口返回 `isSkcGenerateBase=true` 的销售变体字段 |
| 生成依据(方案B) | 默认使用销售变体名称1对应的值 |
| 不可变性 | **SKC编号一旦生成，不会重新生成** |

### 4.5 SKC图显示与校验规则

**方案A（有销售变体配置）**：
| isSkcImageRequired | 前端行为 |
|-------------------|---------|
| true | 显示SKC图上传区域，标记为必填项 |
| false | 不显示SKC图上传区域 |

**方案B（无销售变体配置）**：
- 前端默认显示SKC图上传区域，固定为**非必填**
- 若上传了SKC图，则校验SKC图与值是否对应

**SKC图校验触发场景**：
1. 货品池选品时
2. 供应商门户商品管理-待完善/已选品状态编辑保存时
3. 待同步商品列表编辑保存时

## 五、货品池模块

### 5.1 选品校验规则
选品后系统自动判断必填项完整性，不完善标签包含：

**必填项检查清单**：
- [ ] 属性/物流包装
- [ ] SKU规则（SKU货号/尺码/颜色/供货价/库存/海外仓库存/长宽高/重量）
- [ ] 主图/尺码图/SKC图/详情图（SKC图需对应颜色）

### 5.2 审核功能
- 触发条件：商品状态为**已选品&子状态为待审核**
- 审核驳回：修改数据还原
- 审核通过：更新已选品列表并自动同步到商品运营平台

### 5.3 重新选品
- 对象：未选中状态商品
- 操作：点击重新选品→确认弹窗→状态流转为待选品

## 七、内部商品需求管理模块

### 7.1 需求生成规则

#### 触发方式
| 方式 | 说明 | 规则 |
|-----|------|------|
| 定时触发 | 每天定时聚合 | 生成前主动更新易仓库存 |
| 手动触发 | 特殊场景使用 | 根据最新订单重新生成 |

#### 生成范围排除规则
- SPU商品状态为海外仓 → 不生成
- 供给方式为AIGC → 不生成

#### 需求计算公式
```
缺货数量 = 需求数量 - 可用库存 - 在途数量
```
- 结果≤0时不生成需求单
- 需求数量：已支付且未发货/部分发货的SKU数量
- 可用库存：易仓默认仓库可用库存
- 在途数量：待确认+待下单+待接单+已接单+进行中的SKU数量

### 7.2 内部商品需求类型标签

| 商品类型 | 标签名称 | 识别规则 |
|---------|---------|---------|
| POD商品 | POD | 来源商品类型字段 |
| 自研商品 | 自研 | 来源商品类型字段 |
| 现货商品 | 现货 | 来源商品类型字段 |

### 7.3 自动创建内部商品需求拆分规则

| 规则项 | 说明 |
|-------|------|
| 拆分维度 | 现货/POD商品按类型+供应商维度拆分生成内部商品需求单 |
| POD规则 | POD商品取默认供应商（isDefault=true） |
| 无供应商处理 | 没有供应商信息的SKU单独聚合成一个内部商品需求单 |

### 7.4 手动创建内部商品需求规则

#### 商品选择规则（POD商品）
| 规则项 | 说明 |
|-------|------|
| 展示维度 | POD商品按SKU维度展示，每个SKU为一行 |
| 搜索支持 | 支持SPU、SKC、SKU、供应商名称模糊搜索 |
| 多选支持 | 支持一次选择多个POD商品SKU |

#### 供应商切换联动规则
| 操作 | 结果 |
|-----|------|
| 选择商品 | 默认填充默认供应商的供货价、备货主体、税率、采购员、收款人 |
| 切换供应商 | 采购价、备货主体、税率、采购员、收款人自动更新为新供应商的数据 |
| 手动修改采购价 | 保存修改后的值，不自动更新 |

### 7.5 导入内部商品需求规则

**模板字段（SKU维度）**：
| 字段名称 | 是否必填 | 说明 |
|---------|---------|------|
| SKU编码* | 是 | 需与系统内SKU匹配 |
| 需求数量 | 否 | 正整数 |
| 税率 | 否 | 不填写系统默认13% |
| 下单单价 | 否 | 采购单价 |
| 备货主体* | 是 | 按系统内名称全称匹配 |
| 收款人* | 是 | 按系统内名称全称匹配 |
| 采购员 | 否 | 填入内部采购人员工号 |

## 八、采购单管理模块

### 8.1 采购单状态体系

| 状态 | 触发条件 |
|-----|---------|
| 待采购 | 非1688采购且供应商未开启门户接单 |
| 审核中 | 发起审核申请 |
| 采购异常 | 异常情况 |
| 进行中-待接单 | 供应商开启门户接单，同步成功 |
| 进行中-待发货 | 1688采购下单后 或 供应商接单后 |
| 进行中-同步异常 | 物流信息同步易仓失败 |
| 已完成 | 入库完成 |
| 已撤销 | 手动撤销或自动关单 |

### 8.2 部分发货拆单规则

**触发条件**（满足任一）：
- 未勾选采购单内全部商品
- 勾选商品的发货数量<采购数量

**拆单规则**：
| 单据 | 内容 | 状态 |
|-----|------|------|
| 原采购单 | 已发货部分 | 已完成(同步成功) 或 同步异常 |
| 新采购单 | 未发货部分 | 进行中-待发货 |

### 8.3 超时标签规则

| 标签类型 | 判定公式 |
|---------|---------|
| 接单超时 | 当前时间 - 同步门户时间 > 接单时效配置 |
| 发货超时 | 当前时间 - 同步门户时间 > 发货时效配置 |

**标签清除**：供应商完成接单/发货后自动清除

### 8.4 POD采购单超时规则

POD采购单沿用现有机制，仅时效配置独立：
| 配置项 | 说明 |
|-------|------|
| POD接单时效 | POD采购单的接单超时时间（单位：小时） |
| POD发货时效 | POD采购单的发货超时时间（单位：小时） |
| POD关单时效 | POD采购单的自动关单时间（单位：小时） |

### 8.5 审核流程

#### 缺货审核
**部分商品缺货→审核通过**：
- 门户订单：状态变更为待接单，缺货SKU标记"缺货已审核"
- 采购单：自动拆单，缺货商品拆出新单，状态为已撤销
- 需求单：缺货SKU状态变为已终止
- 库存：缺货SKU库存更新为0并同步

**全部商品缺货→审核通过**：
- 门户订单：状态变为已撤销
- 采购单：状态变为已撤销
- 需求单：所有SKU状态变为已终止

### 8.6 自动关单规则

**适用状态**：待采购、审核中、进行中-待接单、进行中-待发货(非1688)

**触发条件**：当前时间 - 同步门户时间 > 关单时效配置

**处理流程**：
1. 门户订单状态变为已取消
2. 采购单状态变为已撤销
3. 需求单SKU状态变为已终止
4. 触发钉钉群通知

## 九、供应商门户采购订单模块

### 9.1 订单状态流转

| 订单状态 | 触发条件 | 可操作按钮 |
|---------|---------|-----------|
| 待接单 | 采购单同步至门户 | 接单、申请缺货、查看详情、查看日志 |
| 审核中 | 供应商发起申请 | 取消申请、查看详情、查看日志 |
| 已接单 | 供应商操作接单 | 发货、查看详情、查看日志 |
| 部分发货 | 部分商品发货 | 继续发货、查看详情、查看日志 |
| 已发货 | 全部商品发货 | 查看详情、查看日志 |
| 已入库 | 入库完成 | 查看详情、查看日志 |
| 部分入库/已退货 | 部分入库 | 查看详情、查看日志 |
| 已取消 | 采购单撤销 | 查看详情、查看日志 |

### 9.2 倒计时规则

| 类型 | 启动时机 | 计算规则 |
|-----|---------|---------|
| 接单倒计时 | 采购单同步门户后 | 接单时效 - (当前时间 - 同步时间) |
| 发货倒计时 | 供应商接单后 | 发货时效 - (当前时间 - 同步时间) |

**展示格式**：全部换算为小时，精确到时分（例：25小时30分）

### 9.3 发货操作规则

**发货数量校验**：
- 仅允许正整数
- ≤对应商品剩余发货数量
- 超出则前端拦截

**发货判定**：
| 条件 | 结果状态 |
|-----|---------|
| 未勾选全部商品 或 发货数量<采购数量 | 部分发货 |
| 勾选全部商品 且 发货数量=采购数量 | 已发货 |

### 9.4 POD采购订单特殊功能

#### 生产资料展示
| 字段 | 说明 |
|-----|------|
| POD标识 | 仅POD采购订单显示"POD"标签 |
| 版型号 | POD商品的版型编号 |
| 版型图 | POD商品的版型设计图 |
| 花型图案 | POD商品的花纹设计图 |

**数据获取**：实时调用款式开发平台接口获取，不做本地存储

#### 图包下载规则
| 规则项 | 说明 |
|-------|------|
| 文件格式 | ZIP压缩包 |
| 图片格式 | jpg或png（原格式） |
| 单个下载结构 | 采购订单号 → SKU_版型号 → 版型图和花型图案 |
| 批量下载结构 | 年月日时分秒 → 采购订单号 → SKU_版型号 → 版型图和花型图案 |

**批量下载触发条件**：选中的采购订单中至少有一个POD订单时可点击

### 9.5 SKU条码打印

**打印规则**：
- 条码类型：CODE128
- 打印内容：内部SKU + 颜色/尺码（英文名）
- 单个SKU打印1张

## 十、供应商管理模块

### 10.1 新增字段配置

| 字段 | 类型 | 数据源 | 必填时机 |
|-----|------|-------|---------|
| 门户接单开关 | 开关 | - | 默认关闭 |
| 备货主体 | 下拉单选 | 香港/广州杉缔智衣 | 合作中等状态 |
| 收款人 | 下拉单选 | 供应商列表(排除淘汰) | 合作中等状态 |
| 税率 | 数字(2位小数) | 香港→0%，广州→13% | 合作中等状态 |

### 10.2 字段修改规则

**可修改场景**：待提交、待实地验厂、合作中、验厂资料驳回

**不可修改场景**：已淘汰、未验厂取消

**联动规则**：修改备货主体时，税率自动刷新

### 10.3 门户接单开关规则
- 开关默认关闭，关闭后采购单状态默认待采购
- 开关从开启改为关闭时，未完结订单仍可正常操作

## 十四、全局规则索引

### A系列规则（自动创建内部商品需求）
- A1：POD商品按默认供应商维度拆分生成内部商品需求单
- A2：有几个默认供应商，就生成几个内部商品需求单
- A3：每个SKU归属其默认供应商，不重复拆分
- A4：没有供应商信息的SKU单独聚合成一个内部商品需求单

### C系列规则（品类选择）
- C1：商品创建成功后，一级品类不可修改
- C2：创建商品时，选择一级品类后动态渲染销售变体配置
- C3：销售变体配置依据一级品类获取，商品属性配置依据末级品类获取

### S系列规则（销售变体）
- S1：每次导入仅支持一个一级品类
- S13：商品创建时保存销售变体配置快照
- S14：编辑时使用商品绑定的配置快照
- S17：商品属性不使用配置快照，始终使用品类库最新配置

### K系列规则（SKC）
- K1：SKC编号格式：{SPU编码}-{2位递增序号}
- K6：SKC编号一旦生成，不会重新生成
- K11：SKC图必填校验场景：货品池选品、编辑保存

### P系列规则（SKU属性展示）
- P1：SKU属性拼接：SKC生成依据字段在前，其他字段在后
- P2：原来的"颜色"、"尺码"两列合并为"SKU属性"一列

### O系列规则（POD采购单超时）
- O1：POD采购单的接单时效、发货时效、关单时效独立配置
- O2：POD采购单超时标签显示、钉钉通知、自动关单等逻辑与普通采购单一致

## 十五、术语表

| 术语 | 定义 |
|-----|------|
| SPU | 标准化产品单元，代表一类商品的核心信息集合 |
| SKU | 库存保有单位，代表SPU下具体规格的可售库存单元 |
| SKC | SKU Code，SKU编码维度，表示同款同色的商品集合 |
| POD | Print on Demand，按需打印商品 |
| AIGC | AI生成内容商品 |
| 1688采购 | 通过1688平台下单采购 |
| 在途 | 已下单未入库的商品数量 |
| 缺货数量 | 需求数量 - 可用库存 - 在途数量 |
| 销售变体 | SKU维度属性，区分同一商品不同规格（如颜色、尺码） |
| 商品属性 | SPU维度属性，描述商品基本特征 |
| 版型号 | POD商品的版型编号 |
| 版型图 | POD商品的版型设计图 |
| 花型图案 | POD商品的花纹设计图 |
| 配置快照 | 商品创建时保存的销售变体配置副本 |
