## 交互设计文档模板

### 一、交互流程图

```
┌──────────┐    点击按钮    ┌──────────┐    验证通过    ┌──────────┐
│  初始状态  │ ──────────→ │  加载状态  │ ──────────→ │  成功状态  │
└──────────┘              └──────────┘              └──────────┘
                                │
                                │ 验证失败
                                ↓
                          ┌──────────┐
                          │  错误提示  │
                          └──────────┘
```

### 二、交互状态定义

#### 状态列表

| 状态名称 | 状态码 | 触发条件 | 页面表现 |
|---------|-------|---------|---------|
| 初始态 | 0 | 页面加载完成 | 显示默认内容 |
| 加载态 | 1 | 发起请求 | 显示Loading |
| 成功态 | 2 | 请求成功 | 显示结果数据 |
| 空状态 | 3 | 数据为空 | 显示空状态占位图 |
| 错误态 | 4 | 请求失败 | 显示错误提示 |
| 禁用态 | 5 | 条件不满足 | 按钮置灰不可点击 |

#### 状态转换表

| 当前状态 | 用户操作 | 目标状态 | 备注 |
|---------|---------|---------|------|
| 初始态 | 点击提交 | 加载态 | 禁止重复点击 |
| 加载态 | 请求成功 | 成功态 | 显示成功Toast |
| 加载态 | 请求失败 | 错误态 | 显示错误原因 |
| 错误态 | 点击重试 | 加载态 | 重新发起请求 |

### 三、手势交互

| 手势类型 | 适用场景 | 触发条件 | 响应行为 |
|---------|---------|---------|---------|
| 点击 | 按钮、链接 | 手指抬起 | 执行点击事件 |
| 长按 | 删除、编辑 | 按压≥500ms | 弹出操作菜单 |
| 左滑 | 列表项操作 | 滑动距离≥80px | 显示删除按钮 |
| 下拉 | 刷新数据 | 下拉≥60px | 触发刷新 |
| 上拉 | 加载更多 | 滚动到底部 | 触发加载更多 |

### 四、动效规范

| 动效类型 | 时长 | 缓动函数 | 应用场景 |
|---------|------|---------|---------|
| 淡入淡出 | 200ms | ease-in-out | 弹窗显示/隐藏 |
| 滑动 | 300ms | ease-out | 页面切换 |
| 缩放 | 150ms | ease | 按钮点击反馈 |
| 骨架屏 | 1500ms | linear | 加载占位动画 |

## 组件设计规范模板

### 组件：[按钮 Button]

#### 1. 组件概述
- 用途：触发操作或提交表单
- 分类：主要按钮、次要按钮、文字按钮、禁用按钮

#### 2. 组件样式

| 类型 | 背景色 | 文字色 | 边框 | 圆角 | 高度 |
|------|-------|-------|------|------|------|
| 主要按钮 | #1890FF | #FFFFFF | 无 | 4px | 40px |
| 次要按钮 | #FFFFFF | #1890FF | 1px #1890FF | 4px | 40px |
| 文字按钮 | 透明 | #1890FF | 无 | - | auto |
| 禁用按钮 | #F5F5F5 | #BFBFBF | 无 | 4px | 40px |

#### 3. 组件状态

| 状态 | 样式变化 | 触发条件 |
|------|---------|---------|
| 默认态 | 正常样式 | 页面加载 |
| 悬停态 | 背景色加深10% | 鼠标悬停 |
| 按下态 | 背景色加深20% | 鼠标按下 |
| 禁用态 | 置灰，cursor: not-allowed | 条件不满足 |
| 加载态 | 显示Loading图标 | 异步操作中 |

#### 4. 组件属性

| 属性名 | 类型 | 默认值 | 必填 | 说明 |
|--------|------|-------|------|------|
| type | string | primary | 否 | 按钮类型 |
| size | string | middle | 否 | 尺寸：small/middle/large |
| disabled | boolean | false | 否 | 是否禁用 |
| loading | boolean | false | 否 | 是否加载中 |
| icon | string | - | 否 | 图标名称 |
| onClick | function | - | 否 | 点击回调 |

#### 5. 使用示例

```
主要按钮：<Button type="primary">提交</Button>
次要按钮：<Button type="secondary">取消</Button>
禁用按钮：<Button disabled>不可点击</Button>
加载按钮：<Button loading>提交中</Button>
```
