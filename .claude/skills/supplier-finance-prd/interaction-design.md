## 交互设计规范

### 状态颜色规范

| 状态类型 | 颜色代码 | 使用场景 |
|---------|---------|---------|
| 成功/已完成 | #52C41A (绿色) | 已结算、已完成、已通过 |
| 进行中 | #1890FF (蓝色) | 已确认、已付款 |
| 待处理 | #FA8C16 (橙色) | 待确认 |
| 警告/异常 | #FF4D4F (红色) | 异议中、已驳回、异常 |
| 默认/禁用 | #BFBFBF (灰色) | 已撤回、禁用状态 |

### 按钮样式规范

| 按钮类型 | 样式 | 使用场景 |
|---------|------|---------|
| 主要按钮 | 蓝色填充 | 确认、提交、保存 |
| 次要按钮 | 蓝色边框 | 取消、导出 |
| 危险按钮 | 红色填充 | 删除、驳回 |
| 文字按钮 | 无边框文字 | 查看详情、更多 |
| 禁用按钮 | 灰色填充 | 条件不满足时 |

### 反馈提示规范

| 提示类型 | 显示位置 | 持续时间 | 使用场景 |
|---------|---------|---------|---------|
| 成功提示 | 页面顶部居中 | 3秒自动消失 | 操作成功 |
| 错误提示 | 页面顶部居中 | 5秒自动消失 | 操作失败、校验错误 |
| 警告提示 | 页面顶部居中 | 4秒自动消失 | 需注意的情况 |
| 确认弹窗 | 页面居中浮层 | 需手动关闭 | 重要操作二次确认 |
| Loading | 按钮上/页面中央 | 操作完成消失 | 异步操作中 |

### 交互逻辑

#### 1. 页面加载

```
用户进入页面
    │
    ├─→ 系统查询供应商基础信息
    │       │
    │       └─→ 显示供应商名称、编码
    │
    └─→ 系统查询供应商结算配置
            │
            ├─→ 存在配置：显示配置信息（查看模式）
            │
            └─→ 不存在配置：显示空表单（编辑模式）
```

#### 2. 点击"编辑"按钮

```
用户点击[编辑]
    │
    ├─→ 校验用户权限
    │       │
    │       ├─→ 有权限：表单变为可编辑状态
    │       │       │
    │       │       └─→ 按钮变为[取消][保存]
    │       │
    │       └─→ 无权限：提示"您没有编辑权限"
    │
    └─→ 校验对账单状态
            │
            └─→ 存在进行中的对账单：提示警告
                    "存在进行中的对账单，修改后下一周期生效"
```

#### 3. 选择结算方式

```
用户选择结算方式
    │
    ├─→ 选择"到付"或"款到发货"
    │       │
    │       ├─→ 隐藏"对账日"和"账期天数"字段
    │       │
    │       └─→ 显示提示："该结算方式将自动生成结算单"
    │
    └─→ 选择"周结/半月结/月结"
            │
            ├─→ 显示"对账日"和"账期天数"字段
            │
            └─→ 显示提示："该结算方式将按周期生成对账单"
```

#### 4. 点击"保存"按钮

```
用户点击[保存]
    │
    ├─→ 前端校验
    │       │
    │       ├─→ 必填项校验
    │       │       │
    │       │       └─→ 不通过：字段下方显示红色错误提示
    │       │
    │       ├─→ 银行账号格式校验（16-19位数字）
    │       │
    │       ├─→ 手机号格式校验（11位）
    │       │
    │       └─→ 邮箱格式校验
    │
    ├─→ 校验通过
    │       │
    │       ├─→ 显示Loading状态
    │       │       "保存中..."
    │       │
    │       ├─→ 调用保存接口
    │       │       │
    │       │       ├─→ 成功
    │       │       │       │
    │       │       │       ├─→ 关闭Loading
    │       │       │       │
    │       │       │       ├─→ 显示成功提示
    │       │       │       │       "保存成功"
    │       │       │       │
    │       │       │       ├─→ 表单变为查看模式
    │       │       │       │
    │       │       │       └─→ 刷新页面数据
    │       │       │
    │       │       └─→ 失败
    │       │               │
    │       │               ├─→ 关闭Loading
    │       │               │
    │       │               └─→ 显示错误提示
    │       │                       "保存失败：{错误原因}"
    │       │
    │       └─→ 校验不通过
    │               │
    │               └─→ 滚动到第一个错误字段
    │                       页面提示"请检查表单填写"
```

#### 5. 点击"取消"按钮

```
用户点击[取消]
    │
    └─→ 显示确认弹窗
            ┌─────────────────────────┐
            │      取消编辑？          │
            ├─────────────────────────┤
            │  编辑内容将不会保存      │
            │                         │
            │    [继续编辑] [确认取消] │
            └─────────────────────────┘
            │
            ├─→ 点击[继续编辑]：关闭弹窗
            │
            └─→ 点击[确认取消]：
                    │
                    ├─→ 恢复原始数据
                    │
                    └─→ 表单变为查看模式
```

### 字段联动规则

| 触发条件 | 联动效果 |
|---------|---------|
| 选择"到付"或"款到发货" | 隐藏"对账日"、"账期天数"字段 |
| 选择"月结" | 显示"对账日"字段，默认值1 |
| 选择"周结" | 隐藏"对账日"，账期天数默认7 |
| 选择"半月结" | 隐藏"对账日"，账期天数默认15 |
| 银行账号输入 | 自动格式化，每4位空格分隔显示 |
| 手机号输入完成 | 自动发送验证码按钮可点击 |

## 功能二：结算单自动生成

### 触发场景

```
场景A：到付订单
    │
    └─→ 物流签收 + 代收完成 → 触发生成

场景B：款到发货订单
    │
    └─→ 财务付款确认 → 触发生成
```

### 生成过程交互

#### 1. 生成中状态

```
订单触发生成
    │
    ├─→ 订单列表页：订单行显示"结算单生成中..."标签（灰色闪烁）
    │
    └─→ 操作日志：记录"触发结算单生成"事件
```

#### 2. 生成成功

```
生成成功
    │
    ├─→ 订单列表页
    │       │
    │       ├─→ "结算单生成中..."变为"已结算"标签（绿色）
    │       │
    │       └─→ 显示结算单号链接，可点击跳转
    │
    ├─→ 供应商门户
    │       │
    │       └─→ 结算单列表新增一条记录
    │
    ├─→ 站内信
    │       │
    │       └─→ 供应商收到新消息通知
    │               "【结算通知】您有新的结算单已生成..."
    │
    └─→ 邮件
            │
            └─→ 发送结算单生成邮件（含结算单详情链接）
```

#### 3. 生成失败

```
生成失败
    │
    ├─→ 订单列表页
    │       │
    │       └─→ 显示"生成失败"标签（红色）
    │               点击可查看失败原因
    │
    ├─→ 系统日志
    │       │
    │       └─→ 记录失败原因、堆栈信息
    │
    └─→ 告警通知
            │
            └─→ 发送告警给运维人员
```

### 重试机制

```
生成失败
    │
    ├─→ 第一次重试（间隔5分钟）
    │       │
    │       ├─→ 成功 → 正常流程
    │       │
    │       └─→ 失败 → 继续重试
    │
    ├─→ 第二次重试（间隔10分钟）
    │       │
    │       ├─→ 成功 → 正常流程
    │       │
    │       └─→ 失败 → 继续重试
    │
    ├─→ 第三次重试（间隔15分钟）
    │       │
    │       ├─→ 成功 → 正常流程
    │       │
    │       └─→ 失败 → 放弃重试
    │
    └─→ 放弃后处理
            │
            └─→ 发送人工处理告警
                    创建异常工单
```

### 异议处理交互流程

```
页面加载
    │
    ├─→ 查询异议详情
    │
    ├─→ 查询关联订单信息
    │
    └─→ 自动对比数据差异
            - 采购数量 vs 实收数量
            - 计算差异金额
```

#### 选择"同意调整"

```
用户选择"同意调整"
    │
    ├─→ 显示调整后金额输入框
    │       默认值 = 异议金额
    │
    ├─→ 用户可修改金额
    │       │
    │       └─→ 实时显示调整差异
    │               原金额: ¥95,000
    │               调整后: ¥92,000
    │               调整差额: -¥3,000
    │
    └─→ 准备提交
```

#### 选择"驳回异议"

```
用户选择"驳回异议"
    │
    ├─→ 显示驳回原因输入框
    │
    ├─→ 驳回原因必填
    │       │
    │       └─→ 未填写时提示
    │               "请填写驳回原因"
    │
    └─→ 准备提交
```

#### 提交处理

```
用户点击[提交处理]
    │
    ├─→ 前端校验
    │       │
    │       ├─→ 未选择处理结果
    │       │       └─→ 提示"请选择处理意见"
    │       │
    │       ├─→ 同意调整但金额无效
    │       │       └─→ 提示"请输入有效的调整金额"
    │       │
    │       └─→ 驳回但原因为空
    │               └─→ 提示"请填写驳回原因"
    │
    ├─→ 显示确认弹窗
    │       ┌─────────────────────────────────┐
    │       │         确认处理结果？           │
    │       ├─────────────────────────────────┤
    │       │                                 │
    │       │  处理结果: 同意调整             │
    │       │  调整后金额: ¥92,000            │
    │       │                                 │
    │       │  处理后对账单状态将恢复为待确认 │
    │       │  并重新计算确认截止时间         │
    │       │                                 │
    │       │        [取消]    [确认提交]     │
    │       └─────────────────────────────────┘
    │
    └─→ 确认提交
            │
            ├─→ 显示Loading "处理中..."
            │
            ├─→ 调用处理接口
            │       │
            │       ├─→ 成功
            │       │       │
            │       │       ├─→ 显示成功提示
            │       │       │       "处理成功"
            │       │       │
            │       │       └─→ 跳转到异议列表
            │       │
            │       └─→ 失败
            │               │
            │               └─→ 显示错误提示
            │                       "处理失败：{原因}"
```

### 付款登记交互流程

```
用户点击[付款]
    │
    ├─→ 校验对账单状态
    │       │
    │       └─→ 非"已确认"状态
    │               │
    │               └─→ 提示"对账单未确认，无法付款"
    │
    ├─→ 显示付款登记弹窗
    │       │
    │       └─→ 加载对账单金额信息
    │               - 对账金额
    │               - 已付金额
    │               - 待付金额
    │
    └─→ 用户填写付款信息
            │
            ├─→ 输入付款金额
            │       │
            │       ├─→ 实时校验
            │       │       - 不能超过待付金额
            │       │       - 必须大于0
            │       │
            │       └─→ 实时更新付款进度
            │               例如: 本次付¥50,000 → 进度53%
            │
            ├─→ 选择付款日期
            │       │
            │       └─→ 限制选择今天及之前
            │
            ├─→ 选择付款方式
            │
            ├─→ 输入付款流水号
            │
            └─→ 上传付款凭证
                    │
                    └─→ 可选操作
```
