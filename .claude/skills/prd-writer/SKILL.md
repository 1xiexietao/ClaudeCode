## 使用示例

**快速生成PRD**：
```
请帮我生成一份PRD文档：
需求名称：用户登录功能优化
目标用户：APP注册用户
核心问题：当前登录流程繁琐，流失率高
主要功能：支持手机号一键登录、第三方登录
```

**补充完善PRD**：
```
请帮我完善这份PRD的[具体模块，如"异常处理"]部分：
[粘贴现有PRD内容]
```

**PRD模块生成**：
```
请为"购物车功能"生成详细的功能需求说明，包括：
- 用户故事
- 交互流程
- 业务规则
- 异常处理
```
