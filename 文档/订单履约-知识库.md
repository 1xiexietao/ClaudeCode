## 1. 业务全景

### 系统架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                        跨境电商ERP订单履约体系                         │
├─────────────┬─────────────┬─────────────┬─────────────┬─────────────┤
│  Shopify    │  订单履约    │  供应商门户   │   易仓ERP   │  款式开发   │
│  (订单来源)  │  (拆单中枢)  │  (供应商协同) │  (仓储发货)  │  (商品资料)  │
└─────────────┴─────────────┴─────────────┴─────────────┴─────────────┘
```

### 核心业务流

```
Shopify订单 → 订单履约平台(拆单) → 需求单生成 → 采购单创建 → 供应商门户(接单/发货)
                                                          ↓
                              易仓ERP(入库) ← 入库通知 ← 物流跟踪
```

## 2. 核心实体与数据模型

### 实体关系

| 实体 | 说明 | 关键字段 |
|------|------|----------|
| **客户订单(CCO)** | Shopify原始订单 | order_id, status, created_at |
| **子订单(Sub Order)** | 拆单后的履约单元 | sub_order_id, warehouse_type, status |
| **需求单(Demand)** | 采购需求 | demand_id, sku, qty, supplier_id |
| **采购单(Purchase)** | 供应商采购指令 | purchase_id, supplier_id, status |
| **采购订单(PO)** | 采购单聚合 | po_id, purchase_type, status |
| **入库通知(Inbound)** | 入库指令 | inbound_id, warehouse_id |

### 关键枚举值

**采购类型(purchase_type)**：
- `NORMAL` - 常规采购（系统自动创建）
- `STOCK` - 备货采购（手动创建或批量导入）
- `WAREHOUSE_INVITE` - 仓发邀约（Agent生成）

**订单类型(order_type)**：
- `NORMAL` - 普通订单
- `DROPSHIP` - 代发订单

**商品类型**：
- 现货款 → 匹配"现货"需求
- POD款 → 匹配"POD"需求
- AIGC款 → 匹配"自研款"需求

## 3. 订单状态机

### 3.1 子订单状态（订单履约平台）

```
PENDING → WAITING_INBOUND → READY_SHIP → SHIPPED → COMPLETED
   ↓                                                      ↑
   └──────────────── CANCELLED ────────────────────────────┘
```

| 状态 | 含义 | 触发条件 |
|------|------|----------|
| PENDING | 待处理 | 订单创建，等待拆单 |
| WAITING_INBOUND | 等待入库 | 拆单完成，等待供应商发货入库 |
| READY_SHIP | 待发货 | 已入库，准备发货给买家 |
| SHIPPED | 已发货 | 物流已揽收 |
| COMPLETED | 已完成 | 买家确认收货 |
| CANCELLED | 已取消 | 订单取消 |

### 3.2 供应商门户订单状态

```
待接单 → 已接单 → 部分发货/已发货 → 已入库/部分入库/已退货
  ↓         ↓           ↓
已取消    已取消      已取消
```

| 状态 | 含义 | 操作权限 |
|------|------|----------|
| 待接单 | 等待供应商确认 | 接单/拒绝 |
| 已接单 | 供应商已确认 | 发货 |
| 部分发货 | 部分商品已发货 | 继续发货 |
| 已发货 | 全部商品已发货 | - |
| 已入库 | 仓库已收货入库 | - |
| 部分入库 | 部分商品已入库 | - |
| 已退货 | 买家退货 | - |
| 已取消 | 订单取消 | - |

### 3.3 采购单状态

```
待采购 → 进行中-待接单 → 进行中-待发货 → 已完成
  ↓           ↓                ↓
已撤销      已撤销            已撤销
              ↓
           审核中(缺货申请)
```

### 3.4 DROPSHIP订单状态机

```
待接单 → 待发货 → 已发货 → 已完成
  ↓         ↓
已取消    已取消
```

**特殊规则**：
- DROPSHIP订单无需先接单即可操作拆单和发货
- 发货后不支持修改和取消

## 4. 拆单规则与流程

### 4.1 拆单架构（方案三 - 最终采用）

> **核心约束**：所有拆单操作必须在订单履约平台完成，易仓ERP仅作为发货执行方，不允许拆单/合单。

```
Shopify订单 → 订单履约平台拉单 → Shopify fulfillmentOrderSplit拆单
                                        ↓
                              易仓ERP发货 → 履约平台回写物流
```

### 4.2 首次拆单规则

| 规则 | 条件 | 操作 |
|------|------|------|
| 规则0 | 前置检查 | 仅 `FulfillmentOrder.status = OPEN` 允许拆单 |
| 规则1 | Shopify已按location拆分 | 接收已拆分的fulfillment order |
| 规则2 | 海外仓内多供应商 | 调用 `fulfillmentOrderSplit` 补充拆分 |
| 规则3 | 国内仓 | 按供应商+采购员+是否1688采购三维度拆分 |

### 4.3 二次拆单规则（库存驱动）

| 参数 | 说明 |
|------|------|
| 触发时间 | 订单创建 >= **4天**（原7天调整为4天） |
| 触发条件 | 有库存的子订单 |
| 执行次数 | 每个子订单只能执行**一次**库存驱动二次拆单 |
| 执行时间 | 每日凌晨2点定时触发 |
| 标记字段 | `inventory_split_status`（已拆/未拆） |

### 4.4 子订单号命名规则

```
{前缀}_{Shopify订单号}_{序号}

国内仓：CN_前缀
海外仓：OS_前缀
```

### 4.5 手动拆单规则

- 仅子订单级拆单
- 至少保留1件商品
- 国内仓已同步需先校验易仓状态
- 新增"锁定库存"复选框（仅国内发货订单）

## 5. 采购单生命周期

### 5.1 创建流程

```
需求单生成 → 采购单自动创建 → 同步供应商门户
```

**POD需求拆分维度**：供应商 + 采购员 + 是否1688采购

### 5.2 状态流转

```
┌─────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────┐
│  待采购  │ →  │进行中-待接单 │ →  │进行中-待发货 │ →  │  已完成  │
└─────────┘    └─────────────┘    └─────────────┘    └─────────┘
      ↓              ↓                    ↓
   已撤销          已撤销              已撤销
                    ↓
              ┌─────────┐
              │  审核中  │ (缺货申请)
              └─────────┘
```

### 5.3 关单联动链路

```
门户状态变更 → 采购单状态同步 → 需求单SKU状态更新 → 钉钉通知
```

**自动关单条件**：
| 状态 | 超时时间 | 结果 |
|------|----------|------|
| 待采购 | 配置超时 | 自动撤销 |
| 审核中 | 配置超时 | 自动撤销 |
| 进行中-待接单 | 接单时效超时 | 自动撤销 |
| 进行中-待发货 | 发货时效超时 | 自动撤销（非1688） |

## 7. POD商品履约

### 7.1 POD与普通商品差异

| 维度 | 普通商品 | POD商品 |
|------|----------|---------|
| 需求维度 | SKC维度 | **SKU维度** |
| 拆单规则 | 按供应商 | 按**默认供应商**维度 |
| 采购时效 | 标准时效 | 独立配置（接单/发货/关单） |
| 生产资料 | 无 | 需展示版型号、版型图、花型图案 |
| 图包下载 | 不支持 | 支持单个和批量下载 |

### 7.2 POD采购单标识

- 采购单新增POD标识字段
- 供应商门户支持查看生产资料
- 供应商切换联动更新：采购价、备货主体、税率、采购员、收款人

### 7.3 生产资料数据来源

接口：款式开发平台 POD商品生产资料查询接口（GET）

返回字段：
- 版型号
- 版型图
- 花型图案
- 供应商列表

## 8. 代发订单(DROPSHIP)

### 8.1 与普通订单差异

| 维度 | NORMAL订单 | DROPSHIP订单 |
|------|------------|--------------|
| 价格展示 | 展示 | **不展示（脱敏）** |
| 接单前置 | 需先接单 | **无需接单即可拆单/发货** |
| 拆单功能 | 不支持 | 支持 |
| 缺货申请 | 支持 | 不支持 |
| 发货后修改 | - | 不支持修改和取消 |

### 8.2 数据隔离

- 按供应商编码过滤，供应商只能看到归属自己的订单
- 以子订单为维度展示，支持二级展开查看商品明细

### 8.3 API认证机制

- 认证方式：API Key + Secret
- 签名算法：HMAC-SHA256
- 统一接口 + `order_type` 字段区分订单类型

## 9. 仓发邀约

### 9.1 触发机制

- 外部Agent调用平台接口自动生成需求单
- 定时触发：凌晨2:00
- 仓库配置和收件人配置独立设置

### 9.2 标签规则

| 标签 | 适用范围 | 说明 |
|------|----------|------|
| 仓发邀约 | 所有Agent创建的需求单 | 统一标识 |
| 首次邀约 | 首次邀约的需求单 | 额外标识 |

**标签继承链路**：需求单 → 采购单 → 采购订单

### 9.3 数据统计

供应商工作台展示：
- 邀约SKU数
- 邀约库存数
- 邀约入库数
- 邀约可用库存

## 10. 需求计划与履约关联

### 10.1 双任务架构

| 任务 | 说明 | 执行时间 |
|------|------|----------|
| 任务A | 需求自动生成 | 每天定时执行 |
| 任务B | 履约关联计算 | 任务A结束后10分钟启动 |

### 10.2 核心原则

**"跑批即真相"原则**：
- 所有关联字段仅由任务B在执行时全量重写
- 其他操作不实时触发关联修改

**FIFO分配原则**：
- 按CCO创建时间ASC排序
- 依次消耗供给池

### 10.3 关联数据模型

CCO商品行新增字段：
- `inventory_qty` - 库存覆盖量
- `demand_plan_links` - 关联需求计划明细JSON

## 11. 预警与超时机制

### 11.1 预警配置项

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 接单时效 | 供应商接单倒计时 | 可配置 |
| 发货时效 | 供应商发货倒计时 | 可配置 |

| 仓发邀约触发时间 | Agent定时触发 | 凌晨2:00 |
| 二次拆单触发时间 | 库存驱动拆单 | 凌晨2:00 |

### 11.2 通知渠道

- 钉钉群通知（主要）
- 钉钉单人通知（异常升级）

### 11.3 超时处理流程

```
倒计时开始 → 临近超时预警 → 超时触发 → 钉钉通知 → 自动关单
```

## 13. 关键业务规则速查

### 拆单相关

| 规则 | 说明 |
|------|------|
| 拆单主体 | 所有拆单必须在订单履约平台完成 |
| POD拆单维度 | 供应商+采购员+是否1688采购 |
| 代发供应商拆单 | 按供应商维度拆单（标签含"代发供应商"） |
| 二次拆单限制 | 每个子订单只能执行一次 |
| 二次拆单触发 | 订单创建>=4天 + 有库存 |

### 库存相关

| 规则 | 说明 |
|------|------|
| 库存锁定 | 拆单后有库存子订单同步易仓成功后调用orderVerify锁定 |
| 在途数量 | 排除"待确认"状态的需求单 |
| 库存覆盖量 | sell_one_buy_one场景恒为0 |

### 数据脱敏

| 场景 | 规则 |
|------|------|
| DROPSHIP订单价格 | 不展示 |
| Shopify导出收件人信息 | 不做脱敏 |
| 手机号/地址/成本价 | 默认脱敏 |

### 多供应商支持

| 规则 | 说明 |
|------|------|
| 最大关联数 | 外部商品最多关联5个供应商 |
| 默认供应商 | 设置后自动同步POP平台 |
| 供应商切换 | 联动更新采购价、备货主体、税率、采购员、收款人 |

### 权限控制

| 规则 | 说明 |
|------|------|
| 数据隔离 | 供应商只能看到归属自己的数据 |
| 导出权限 | 必须经过权限校验，记录操作日志 |
| 新增按钮 | 必须配置权限控制 |
