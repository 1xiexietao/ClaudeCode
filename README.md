## 版本管理规范

### 提交规范

```
feat: 新增功能/规则
fix: 修复问题/错误
update: 修改已有内容
remove: 删除内容
refactor: 重构/调整结构
docs: 文档格式调整
```

- `v1.0` - 评审通过版本
