# B端产品 PRD 文档库

产品需求文档版本管理仓库。

## 目录结构

```
├── PRD文档/                    # PRD 文档目录（含业务流程方案、接口文档）
│   ├── 525版本-POD商品履约支持PRD.md
│   ├── 采购异常协作迭代PRD.md
│   ├── 订单履约平台全业务流程图.md
│   └── ...
├── 原型设计/                   # HTML 页面原型
│   ├── order-management.html
│   ├── 采购异常列表.html
│   └── ...
├── 文档/                       # 知识库、汇报等业务文档
│   ├── 订单履约-知识库.md
│   └── 拆单助手Agent建设与成效汇报.md
├── 脚本/                       # Python 脚本
│   ├── main.py
│   └── requirements.txt
├── .claude/                    # Claude Code 配置
│   ├── CLAUDE.md               # 项目规范
│   ├── agents/                 # 自定义代理
│   ├── memory/                 # 记忆系统
│   └── skills/                 # 自定义技能
└── README.md
```

## 目录约定

- **PRD文档/**：所有 PRD 及业务流程方案、接口文档，统一存放于此，不新建其他目录
- **原型设计/**：HTML 页面原型
- **文档/**：知识库、汇报、非 PRD 业务文档
- **脚本/**：Python 脚本及依赖

## 版本管理规范

### 提交规范

```
feat: 新增功能/规则
fix: 修复问题/错误
update: 修改已有内容
remove: 删除内容
refactor: 重构/调整结构
docs: 文档格式调整
```

### 版本标签

- `v1.0` - 评审通过版本
- `v1.1` - 迭代版本
