# 杉缔ERP

多平台订单管理、采购、仓储、物流、财务、报价核算一体化产品线。

## 项目构成

本目录覆盖杉缔ERP 生态内的多个关联系统，PRD 与原型统一沉淀于此：

- 订单履约平台（多平台订单管理、拆单、采购需求、入库通知）
- 供应商门户（推品、订单交互、商品属性动态化）
- 供应商财务对账
- 易仓ERP 采购协同（采购异常协作、接口对接）
- 自动拆单 Agent

## 目录结构

```
杉缔ERP/
├── PRD文档/        # PRD 文档（含业务流程方案、接口文档）
├── 原型设计/       # HTML 页面原型
├── 文档/           # 知识库、汇报等非 PRD 业务文档
├── 脚本/           # Python 脚本及依赖
└── README.md
```

## 版本管理规范
