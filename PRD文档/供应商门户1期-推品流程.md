# 供应商门户1期-推品流程完善产品需求文档

## 一、文档概述

### 1.1 文档目的

本文档用于明确**供应商门户**的功能范围、业务流程、交互规则与非功能需求，为业务、开发、测试团队提供统一的需求依据，确保供应商端商品管理、货品池运营、已选品同步等核心场景高效落地。

### 1.2 适用范围

*   **参与部门**：供应商BD、买手、仓储物流、技术团队
    
*   **核心模块**：商品管理、货品池、已选品列表、供应商管理
    

### 1.3 术语定义

| 术语 | 定义 |
| --- | --- |
| SPU | 标准化产品单元，代表一类商品的核心信息集合 |
| SKU | 库存保有单位，代表SPU下具体规格（颜色/尺码等）的可售库存单元 |
| 草稿 | 商品未推品的初始状态 |
| 待选品 | 商品进入买手货品池，等待买手筛选 |
| 已选品 | 买手确认选中，流入到已选品列表 |
| 已选品-待审核 | 供应商发起修改数据，待审核状态 |
| 未选中 | 买手淘汰的商品 |
| 已取消推品 | 供应商撤回推品的状态 |

1.  **商品创建与管理**：供应商新建/编辑商品信息，批量导入商品/图片/价格库存，管理商品状态。

## 三、功能模块详情

### 3.1 商品管理

#### 3.1.1 商品列表

*   **筛选能力**：支持按商品状态、商品名称、SPU货号、品类、供应商、标签等维度筛选。
    
*   **展示字段**：商品状态、图片、名称、供货价、品类、库存、SPU货号、仓库类型、供应商名称。
    
*   **状态维度**：
    
    *   供应商维度：草稿、已推品、待完善、已选品、已选品-待审核、未选中、已取消推品
        
    *   内部货品池维度：草稿、待选品、选品中、已选品、已选品-待审核、未选中、已取消推品
        
*   供应商只能看到商品归属于自己供应商的数据
    
*   内部账号可以看到全部供应商的数据
    

#### 3.1.2 新建商品

*   **必填字段**：商品名称、商品分类、仓库类型、SPU货号
    
*   **可选字段**：商品属性（按大类填写）、物流包装
    
*   **SKU信息**：必须至少有1个SKU，颜色/尺码/供货价/库存为必填项
    
*   **图片要求**：商品主图必填，详情图/主图/SKC图/尺码图按供应商需求调整
    

#### 3.1.3 批量导入能力

| 导入类型 | 支持维度 | 核心步骤 |
| --- | --- | --- |
| 批量导入商品 | SPU/SKU | 选择维度 → 上传文件 → 数据预览（支持下载错误原因） → 导入进度 → 导入结果 |
| 批量导入商品属性 | SPU | 选择品类 → 下载模板 → 上传文件 → 数据预览（支持下载错误原因）->确认导入 |
| 批量导入图片 | 图片类型（主图/SKC图/尺码图/详情图） | 1、按命名规则上传文件夹/表格链接 → 系统自动分类匹配<br>2、按照图片类型分别上传<br>3、每种图片类型支持手动标记类型 |
| 批量修改价格/库存 | 商品 | 库存为0时自动更新商品运营为0；有库存变更为库存为0时，自动把商品运营的上架虚拟库存变更为实际库存 |

#### 3.1.4 商品操作按钮

*   **查看**：所有状态商品均可查看
    
*   **编辑**：显示状态；草稿、已选品、待完善
    
    *   草稿/待完善：所有字段允许修改
        
    *   已选品未同步：可修改基础信息（商品名称/分类(不能改一级)/仓库类型/SPU货号）、商品属性、物流包装、SKU规则（新增/删除SKU、颜色/尺码/SKU货号/供货价/库存//海外仓库存/长宽高/重量）、商品图片（仅新增SKC图），修改后状态变为待审核，审核通过后生效
        
    *   已选品已同步：可修改商品属性、SKU规则（新增SKU/供货价/库存/海外仓库存）、商品图片（仅新增SKC图），修改后状态变为待审核，审核通过后生效
        
*   **推品**：草稿状态商品推品后进入买手货品池，买手可在货品池进行选品/淘汰操作
    
*   **取消推品**：显示状态已推品、已选品、待完善
    
    *   已推品/待完善状态：取消后商品状态变为草稿
        
    *   已选品状态：取消后变为已取消推品，需选择取消原因
        
        *   商品状态已选品 && 未同步时，操作取消推品 && 审核通过，商品状态直接变更为已取消推品，已选品列表的商品状态也变更为已取消推品
            
        *   商品状态已选品 && 已同步时，操作取消推品 && 审核通过，商品状态直接变更为已取消推品，已选品列表的商品状态也变更为已取消推品，并调用商品运营平台下架API接口
            
*   **删除**：仅草稿状态可删除，删除后页面不展示，供应商可重新导入相同SPU货号商品
    
*   **日志**：所有状态商品均可查看操作日志
    
*   **导出**：支持导出功能

### 3.2 货品池

#### 3.2.1 列表展示

*   默认选中**待选品**状态，展示待选品数量及明细
    
*   支持按商品状态、仓库类型筛选，新增商品状态tab，切换tab更新对应状态数量
    
*   商品状态维度：草稿、待选品、选品中、已选品、已选品-待审核、未选中、已取消推品
    
*   列表展示形式改为商品卡片列表
    

#### 3.2.2 选品能力

*   **重复AI能力**：判断同款/相似款商品，点击标签可弹窗展示所有同款/相似款商品信息【技术确认能力是否要花钱】
    
*   **选品校验**：选品后系统自动判断必填项是否齐全，打上「不完善」标签，包含：
    
    *   属性/物流包装不完善
        
    *   SKU规则（SKU货号/尺码/颜色/供货价/库存/海外仓库存/长宽高/重量）不完善
        
    *   主图/尺码图/SKC图/详情图不完善（SKC图需对应颜色）
        

#### 3.2.3 审核功能

*   商品状态为**已选品&子状态为待审核**时展示审核按钮
    
*   审核驳回：修改数据还原
    
*   审核通过：更新已选品列表并自动同步到商品运营平台
    

#### 3.2.4 重新选品

*   显示未选中状态商品
    
*   点击重新选品按钮，弹窗提示「确定要操作重新选品吗」，操作后商品状态流转为**待选品**，进入货品池
    

#### 3.2.5同款识别（3-20补充）

*   手动点击触发调用同款识别功能，数据范围：货品池所有有识别失败标签的商品
    
*   识别成功后，移除失败标签

### 3.3 已选品列表

#### 3.3.1 列表展示

*   已选品列表变更为待同步商品列表
    
*   列表新增仓库类型字段，增加仓库类型筛选
    
*   商品状态变更为已选中、未选中、已取消推品
    
    *   原可用变更为已选中
        
    *   淘汰变更为未选中
        
    *   新增已取消推品（买手已选中后，供应商发起取消推品，审核通过后状态未已取消推品）
        
*   尺码图做两套
    
    *   确认供应商能上传尺码图（包含截图）
        
    *   两种类型的尺码图都支持上传、删除
        
    *   以前的尺码图标记为原始尺码图
        
    *   新增MUSE尺码图，同步商品统一用MUSE尺码图
        
    *   与SDP款式开发平台的图片交互，统一改为同步到MUSE尺码图
        
*   支持导出功能
    

#### 3.3.2 自动同步颜色和尺码功能

*   已选品列表创建商品后，自动触发判断：
    
    *   本地库颜色是否存在：不存在则在本地库创建颜色，并同步到易仓
        
    *   本地库尺码是否存在：不存在则在本地库创建尺码，并同步到易仓
        

#### 3.3.3 自动生成尺码图的AI能力

*   已选品列表创建商品信息后，系统自动根据原尺码图，调用AI能力自动生成muse尺码图
    
*   增加AI尺码图的生成状态（待生成、生成中、生成完成、生成失败）
    
    *   默认为待生成、触发任务后变更为生成中、根据生成结果显示生成完成和生成失败
        
    *   待生成、生成完成、生成失败，显示生成尺码图按钮
        
    *   点击生成尺码图按钮，调用AI能力
        
    *   只有生成完成or 待生成的商品，才可以显示同步商品按钮
        

#### 3.3.2 同步与回写

*   新增/编辑/删除操作后，同步成功后触发回写商品运营平台
    
*   平台与供应商接口同步成功后，触发同步商品运营
    
*   已选品列表发起的编辑，不会反向到同步货品池，也就是供应商看不到我们修改后的数据
    
*   若操作淘汰，会联动货品池的商品状态为未选中

## 四、历史数据处理

### 4.1 货品池

*   批量刷商品状态数据：
    
    *   商品状态为淘汰的所有商品，商品状态变更为已淘汰
        
    *   商品状态为可用 && 选品状态为待选品的，商品状态变更为待选品
        
    *   商品状态为可用 && 选品状态为选品中的，商品状态变更为选品中
        
    *   商品状态为可用 && 选品状态为已选品的，商品状态变更为已选品
        

### 4.2 已选品列表（更名为待同步商品列表）

*   批量刷商品状态数据：
    
    *   原可用变更为已选中
        
    *   淘汰变更为未选中
        
    *   新增已取消推品
        
*   初始化本地颜色库：
    
    *   同步SDP颜色库字典里面的颜色名称和易仓颜色ID
        
    *   已选品列表所有商品的颜色落库，并批量同步到易仓颜色
        
*   初始化本地尺码库：
    
    *   同步SDP尺码库字典里面的尺码名称和易仓尺码ID
        
    *   已选品列表所有商品的尺码落库，并批量同步到易仓尺码
        
*   批量刷原始40开头的尺码图：
    
    *   标记为原始尺码图
