## 一、需求背景

为解决供应商对账依赖人工操作、效率低、易出错的问题，实现财务对账流程的数字化、标准化管理，打通从采购需求完成到结算/对账/付款的全流程数据链路，优化财务、采购跟单与供应商的协同效率，降低跨角色沟通成本，特搭建供应商财务对账系统。

## 三、对账单生成规则

### 3.1 结算方式与生成周期

| 结算方式 | 对账单生成周期 | 生成时间 | 对账周期范围 | 编号规则 |
|---------|--------------|---------|-------------|---------|
| **现付** | 按月生成 | 每月1日 08:00 | 上月1日至月末 | DZ + 供应商编码 + 年月<br>例：DZ-SUP001-202604 |
| **周结** | 按周生成 | 每周一 08:00 | 上周一至周日 | DZ + 供应商编码 + 年份 + 周号<br>例：DZ-SUP001-2026-W17 |
| **半月结** | 按半月生成 | 每月1日/16日 08:00 | 上半月(1-15日)/下半月(16-月末) | DZ + 供应商编码 + 年份 + 月份 + H1/H2<br>例：DZ-SUP001-202604-H1 |
| **月结** | 按月生成 | 每月1日 08:00 | 上月1日至月末 | DZ + 供应商编码 + 年月<br>例：DZ-SUP001-202604 |

### 3.3 数据来源与取值规则

| 字段名称 | 数据来源 | 取值规则 |
|---------|---------|---------|
| 对账单号 | 系统生成 | 按编号规则生成 |
| 供应商编码 | 采购需求单 | 汇总维度 |
| 供应商名称 | 供应商主数据 | 关联查询 |
| 对账周期 | 系统计算 | 根据结算方式确定 |
| 采购需求单笔数 | 采购需求单 | COUNT(需求单号) |
| 商品金额 | 采购需求单 | SUM(实收数量 × 采购单价) |
| 其他费用项 | 费用补充记录 | 初始为0，后续由采购跟单/财务补充 |
| 扣款金额 | 扣款记录表 | SUM(扣款金额) |
| 调整金额 | 调整记录表 | SUM(调整金额) |
| 对账金额 | 计算得出 | 商品金额 + 其他费用项 - 扣款金额 + 调整金额 |

### 3.4 对账单自动生成前置条件

| 序号 | 条件 | 校验方式 | 不满足处理 |
|------|------|---------|-----------|
| 1 | 定时任务触发时间到达 | 定时器触发 | - |
| 2 | 供应商状态为"正常" | 查询供应商主数据 | 跳过停用供应商 |
| 3 | 周期内存在已完结采购需求单 | 订单系统查询 | 不生成，记录日志 |
| 4 | 对账金额 > 0 | 计算校验 | 不生成，记录日志 |
| 5 | 单据未在其他对账单中 | 查询去重 | 排除已对账单据 |
| 6 | 该周期未生成过对账单 | 查询去重 | 跳过，避免重复 |

### 5.2 状态定义

| 状态 | 状态码 | 触发条件 | 可执行操作 | 说明 |
|------|-------|---------|----------|------|
| 待确认 | 10 | 对账单生成 | 查看、确认、补充费用、异议、驳回 | 初始状态 |
| 已驳回 | 15 | 采购跟单驳回 | 查看、重新提交 | 采购跟单驳回后 |
| 异议中 | 20 | 供应商提交异议 | 查看、处理异议 | 暂停确认流程 |
| 已确认 | 30 | 供应商确认/自动确认 | 查看、登记付款 | 可进入付款 |
| 已付款 | 40 | 部分付款 | 查看、继续付款 | 等待剩余付款 |
| 已完成 | 50 | 全额付款 | 查看 | 最终状态 |

## 六、详细功能设计

### 6.1 采购跟单工作台

#### 6.1.1 待确认对账单列表

**展示范围**：状态为"待确认"的对账单

**筛选功能**：
- 对账周期

- 结算方式

**展示字段**：
| 字段 | 说明 |

#### 6.1.2 补充其他费用项

**费用类型**：
| 费用类型 | 说明 |

**操作流程**：

**字段说明**：

|---------|------|-----|---------|

| 附件 | 文件上传 | 否 | 图片/PDF，最多5个 |

### 6.2 供应商对账确认

#### 6.2.1 对账确认

**前置条件**：
- 对账单状态为"待确认"
- 采购跟单已确认账单
- 用户为该供应商的授权用户

**操作流程**：
1. 供应商点击"确认对账"按钮
2. 系统弹出确认弹窗
   - 显示对账单号、对账周期、对账金额
   - 提示"确认后将进入付款流程，请确认信息无误后再操作"
   - 勾选框"我已核对对账明细，确认无误"
3. 供应商确认
4. 系统记录确认时间、操作人
5. 更新对账单状态为"已确认"

#### 6.2.2 对账异议提交

**异议类型**：
| 类型 | 说明 | 必填字段 |
|------|------|---------|
| 单据缺失 | 对账单中缺少应有的单据 | 异议说明 |
| 金额错误 | 单据金额计算错误 | 异议金额、异议说明 |
| 费用异议 | 对其他费用项有异议 | 异议金额、异议说明 |
| 其他 | 其他问题 | 异议说明 |

**操作流程**：
1. 供应商点击"提出异议"按钮
2. 系统弹出异议表单
3. 供应商填写异议信息
4. 系统校验
5. 创建异议记录
6. 更新对账单状态为"异议中"
7. 通知采购跟单和财务

**异议撤回**：
- 撤回时限：提交后24小时内
- 撤回后：异议状态变为"已撤回"，对账单状态恢复为"待确认"

### 6.3 财务工作台

#### 6.3.1 对账单审核

| 供应商名称 | 只读 | - | - | 显示供应商名称 |
| 对账金额 | 只读 | - | - | 显示对账金额 |
| 已付金额 | 只读 | - | - | 显示已付款金额 |
| 待付金额 | 只读 | - | - | 对账金额 - 已付金额 |
| 本次付款金额 | 金额输入 | 是 | ≤待付金额且>0 | 本次付款金额 |
| 付款日期 | 日期选择 | 是 | ≤今天 | 实际付款日期 |

## 九、异常场景处理

### 9.1 对账单生成异常

| 异常场景 | 处理方式 |
|---------|---------|
| 周期内无已完结采购需求单 | 不生成对账单，记录日志 |
| 周期内对账金额为0 | 不生成对账单，记录日志 |
| 供应商已停用 | 跳过该供应商，不生成对账单 |
| 重复生成 | 校验并跳过，避免重复 |

### 9.2 异议处理异常

| 异常场景 | 处理方式 |
|---------|---------|
| 异议提交后超过7天未处理 | 发送催办通知给采购跟单/财务 |
| 异议撤回超过24小时 | 不允许撤回，提示"超过撤回时限" |
| 异议重复提交 | 允许，无次数限制 |

### 9.3 付款登记异常

| 异常场景 | 处理方式 |
|---------|---------|
| 付款金额超过待付金额 | 校验拦截，提示"付款金额不能超过待付金额" |
| 付款日期超过今天 | 校验拦截，提示"付款日期不能超过今天" |

### 10.1 术语说明

| 结算方式 | 说明 | 对账周期 |

| 现付 | 货到付款或款到发货 | 按月生成对账单 |
| 周结 | 每周结算一次 | 按周生成对账单 |
| 半月结 | 每半月结算一次 | 按半月生成对账单 |
| 月结 | 每月结算一次 | 按月生成对账单 |
