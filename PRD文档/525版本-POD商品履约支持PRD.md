## 1. 项目背景

### 1.1 业务现状与问题

随着公司业务发展，开展了POD（Print on Demand，按需打印）数码印花商品的新业务线。POD商品的业务链路为：款式开发平台开款 → 商品运营平台上架 → 订单履约平台履约。

目前履约平台在POD商品履约流程中存在以下问题：

| 问题维度 | 当前状态 | 存在问题 |
| --- | --- | --- |
| **内部商品需求创建** | POD商品按SKC维度展示 | 采购跟单无法精确选择到SKU级别，影响采购精细化管理 |
| **采购单标识** | 未区分POD类型 | 供应商无法识别订单类型，影响生产准备 |
| **生产资料获取** | 供应商门户未展示 | 供应商需线下沟通获取版型图、花型图案，效率低下 |
| **供应商信息** | 未对接款式开发平台 | 无法获取POD商品的多供应商及供货价信息 |

### 1.2 改造目标

| 改造方向 | 目标方案 | 核心价值 |
| --- | --- | --- |
| 内部商品需求创建 | 从"SKC维度"升级为"SKU维度" | 支持精确选择POD商品SKU，支持切换供应商 |
| 内部商品需求生成 | POD商品按默认供应商维度拆分生成，无供应商SKU单独聚合 | 精细化管理不同供应商的内部商品需求 |
| 采购单标识 | 新增POD类型标识 | 区分POD订单与普通订单 |
| 生产资料展示 | 供应商门户展示生产资料 | 供应商可查看版型号、版型图、花型图案并下载 |
| 供应商信息对接 | 对接款式开发平台接口 | 获取POD商品的生产资料和多供应商供货价信息 |

## 3. 术语说明

| 术语 | 定义 |
| --- | --- |
| **POD** | Print on Demand，按需打印，数码印花商品 |
| **SPU** | Standard Product Unit，标准产品单位，商品的基本信息单位 |
| **SKC** | SKU Code，SKU编码维度，表示同款同色的商品集合 |
| **SKU** | Stock Keeping Unit，库存量单位，最细粒度的商品单位（颜色+尺码） |
| **版型号** | POD商品的版型编号，用于标识商品版型 |
| **版型图** | POD商品的版型设计图，用于生产参考 |
| **花型图案** | POD商品的花纹设计图，用于生产参考 |
| **生产资料** | POD商品生产所需的资料，包含版型号、版型图、花型图案 |
| **默认供应商** | 款式开发平台为POD商品设置的默认供货供应商 |
| **履约平台** | 订单履约平台，负责内部商品需求、采购单、入库等履约流程管理 |
| **供应商门户** | 供应商协同平台，供应商查看和操作采购订单的入口 |
| **款式开发平台** | 商品开款平台，管理商品款式、版型、供应商等信息 |

### 4.2 自动创建内部商品需求规则

#### 4.2.1 拆分规则

| 规则项 | 说明 |
| --- | --- |
| 拆分维度 | 现货/POD商品按类型+供应商维度拆分生成内部商品需求单 |
| 拆分数量 | 有几个供应商，就生成几个内部商品需求单 |
| SKU归属 | 每个SKU归属其默认供应商，不重复拆分 |
| 无供应商处理 | 没有供应商信息的SKU单独聚合成一个内部商品需求单 |
| POD规则 | POD商品取默认供应商 |
| 供应商归属 | 供应商必须要在履约平台供应商列表里存在 |



#### 4.2.2 拆分示例

**场景：** 一批POD商品有5个SKU，分别属于不同供应商

| SKU | 默认供应商 | 供应商信息 |
| --- | --- | --- |
| SKU001 | 供应商A | 有 |
| SKU002 | 供应商A | 有 |
| SKU003 | 供应商B | 有 |
| SKU004 | 供应商B | 有 |
| SKU005 | 无 | 无供应商信息 |

**生成结果：** 3个内部商品需求单

| 内部商品需求单 | 供应商 | 包含SKU | 采购价来源 |
| --- | --- | --- | --- |
| 内部商品需求单1 | 供应商A | SKU001、SKU002 | 供应商A的供货价 |
| 内部商品需求单2 | 供应商B | SKU003、SKU004 | 供应商B的供货价 |
| 内部商品需求单3 | 无 | SKU005 | 留空 |

#### 4.2.3 字段取值规则

| 默认字段 | 取值规则 | 无值处理 |
| --- | --- | --- |
| 销售渠道 | 固定值：独立站-shopify | — |
| 供应商名称 | 款式开发平台接口返回的默认供应商（isDefault=true） | 留空 |
| 采购价 | 款式开发平台接口返回的默认供应商供货价 | 留空 |
| 备货主体 | 根据供应商名称，查询供应商列表的备货主体配置 | 留空 |
| 税率 | 根据供应商名称，查询供应商列表的税率配置 | 留空 |
| 采购员 | 根据供应商名称，查询采购策略配置中绑定的采购/跟单人 | 留空 |
| 收款人 | 根据供应商名称，查询供应商列表的收款人配置 | 留空 |

#### 4.2.4 业务规则

| 编号 | 规则类型 | 规则描述 |
| --- | --- | --- |
| A1 | 约束 | POD商品自动创建内部商品需求时，按默认供应商维度拆分生成内部商品需求单 |
| A2 | 计算 | 有几个默认供应商，就生成几个内部商品需求单 |
| A3 | 计算 | 每个SKU归属其默认供应商，不重复拆分 |
| A4 | 计算 | 没有供应商信息的SKU单独聚合成一个内部商品需求单 |
| A5 | 计算 | 根据供应商名称查询供应商列表获取备货主体、税率 |

### 4.9 导入内部商品需求规则

#### 4.9.1 模板字段说明

导入模板从SKC维度调整为SKU维度，模板字段如下：

| 字段名称 | 是否必填 | 字段格式 | 说明 |
| --- | --- | --- | --- |
| SKU编码* | 是 | 文本 | SKU编码，需与系统内SKU匹配 |
| 需求数量 | 否 | 正整数 | 只能为大于0的正整数 |
| 税率 | 否 | 正整数 | 按百分之多少填写（如10，则为10%），不填写系统默认13 |
| 下单单价 | 否 | 数字（最多2位小数） | 采购单价 |
| 备货主体* | 是 | 文本 | 按系统内名称全称匹配 |
| 收款人* | 是 | 文本 | 按系统内名称全称匹配 |
| 采购员 | 否 | 文本 | 填入内部采购人员工号 |

#### 4.9.2 导入规则

| 编号 | 规则类型 | 规则描述 |
| --- | --- | --- |
| I1 | 约束 | 导入模板从SKC维度调整为SKU维度 |
| I2 | 约束 | 星标列为必填项，未填写则过滤不予导入 |
| I3 | 约束 | 非必填项可以在导入成功后在页面编辑修改 |
| I4 | 计算 | 期望货期无填值时，系统按导入日期自行计算 |
| I5 | 计算 | 备货主体、收款人按系统内名称全称匹配，匹配失败则过滤不予导入 |
| I6 | 计算 | 采购员填入内部采购人员工号，数据有误则过滤不予导入 |
| I7 | 约束 | 如导入SKU重复，则重复数据都过滤不予导入 |
| I8 | 计算 | 若需求数量和下单价格均有填写，导入时系统自动计算总金额（不含税）= 需求数量 × 下单单价 |
| I9 | 计算 | 采购仓库取系统默认采购仓库配置 |
| I10 | 计算 | 联系人员取系统默认收件人、电话、地址配置 |

#### 8.1.3 图包下载

**功能概述**：供应商点击"图包下载"按钮，系统将版型图和花型图案打包为ZIP文件下载。支持单个订单下载和批量下载。

**下载入口**：

| 入口位置 | 说明 | 触发条件 |
| --- | --- | --- |
| 订单列表-批量图包下载按钮 | 批量下载选中订单的图包 | 选中的采购订单中至少有一个POD订单时可点击 |
| 订单列表-订单列图包下载按钮 | 单个订单图包下载 | 仅POD采购订单显示该按钮，非POD订单不显示 |

**下载规则**：

| 规则项 | 说明 |
| --- | --- |
| 文件格式 | ZIP压缩包 |
| 图片命名 | 版型图：版型图.jpg；花型图案：花型图案.jpg |
| 图片格式 | jpg或png（原格式） |
| 单个下载结构 | 采购订单号 → SKU_版型号 → 版型图和花型图案 |
| 批量下载结构 | 年月日时分秒 → 采购订单号 → SKU_版型号 → 版型图和花型图案 |

**单个订单下载流程**：

| 步骤 | 操作 | 系统响应 |
| --- | --- | --- |
| 1 | 供应商点击订单列"图包下载"按钮 | 系统调用款式开发平台接口获取图片URL |
| 2 | 接口返回成功 | 系统下载图片并打包为ZIP文件 |
| 3 | 打包完成 | 浏览器自动下载ZIP文件 |
| 4 | 接口返回失败 | 提示"获取图片失败，请稍后重试" |

**批量下载流程**：

| 步骤 | 操作 | 系统响应 |
| --- | --- | --- |
| 1 | 供应商勾选多个采购订单 | 系统校验选中订单是否包含POD订单 |
| 2 | 点击"批量图包下载"按钮 | 至少有一个POD订单时按钮可点击，否则按钮置灰 |
| 3 | 系统处理 | 仅下载POD订单的图包，非POD订单自动跳过 |
| 4 | 调用款式开发平台接口 | 批量获取POD订单的图片URL |
| 5 | 打包完成 | 浏览器自动下载ZIP文件，包含所有POD订单图包 |
| 6 | 接口返回失败 | 提示"获取图片失败，请稍后重试" |

**下载文件结构**：

单个订单下载：
```
采购订单号/
├── {SKU1_版型号}/
│   ├── 版型图.jpg
│   └── 花型图案.jpg

│   └── 花型图案.jpg

```

批量下载：
```
{年月日时分秒}/
├── {采购订单号1}/
│   ├── {SKU1_版型号}/
│   │   ├── 版型图.jpg
│   │   └── 花型图案.jpg
│   └── {SKU2_版型号}/
│       ├── 版型图.jpg
│       └── 花型图案.jpg
├── {采购订单号2}/
│   ├── {SKU1_版型号}/
│   │   ├── 版型图.jpg
│   │   └── 花型图案.jpg
│   └── ...
└── ...
```

## 10. 异常情况处理方案

### 10.1 接口相关异常

| 异常类型 | 异常场景 | 处理方案 |
| --- | --- | --- |
| 接口超时 | 款式开发平台接口响应超过设定时间 | 内部商品需求创建失败，提示"获取商品信息失败，请稍后重试" |
| 接口失败 | 款式开发平台接口返回错误码 | 内部商品需求创建失败，提示"获取商品信息失败，请联系管理员" |
| 数据为空 | 接口返回数据为空 | 内部商品需求创建失败，提示"商品信息不完整，请联系管理员" |
| 无供应商数据 | 接口返回的供应商列表为空 | 内部商品需求创建失败，提示"该商品暂无供应商信息" |

### 10.2 图片相关异常

| 异常类型 | 异常场景 | 处理方案 |
| --- | --- | --- |
| 图片加载失败 | 版型图/花型图案URL无效或加载失败 | 图片区域显示占位图，提示"图片加载失败" |
| 图片下载失败 | 图包下载时图片下载失败 | 提示"下载失败，请稍后重试" |
| 图片URL无效 | 图片URL不存在或已失效 | 提示"图片资源不可用，请联系采购" |

### 10.3 其他异常

| 异常类型 | 异常场景 | 处理方案 |
| --- | --- | --- |
| 网络异常 | 提交操作时断网 | 本地暂存已填写内容，恢复后提示重新提交 |
| 并发冲突 | 多人同时编辑同一内部商品需求 | 沿用现有乐观锁机制，后提交者需刷新确认 |
