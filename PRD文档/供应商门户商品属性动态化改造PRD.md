## 1. 项目背景

### 1.1 业务现状与问题

供应商门户商品管理模块涉及三类属性需要改造：

| 属性类型 | 维度 | 当前模式 | 存在问题 |
| --- | --- | --- | --- |
| **商品属性** | SPU | 固定模板模式，预设6个大类的固定属性字段 | 属性维护需代码发版；与商品运营平台品类库不同步 |
| **销售变体** | SKU | 固定字段模式，仅支持颜色、尺码 | 无法根据品类配置不同变体；批量导入模板固定 |
| **SKC图** | SKC | 固定与"颜色"字段关联 | SKC图必填校验固定；SKC编号生成依据固定 |

### 1.2 改造目标

| 改造方向 | 目标方案 | 核心价值 |
| --- | --- | --- |
| 商品属性 | 从"固定模板"升级为"动态配置" | 实时读取商品运营平台品类库，变更即时生效 |
| 销售变体 | 从"固定字段"升级为"动态配置" | 不同品类可配置不同销售变体组合 |
| SKC图 | 从"固定关联颜色"升级为"动态配置" | SKC图必填和SKC编号生成依据均可配置 |

## 3. 术语说明

| 术语 | 定义 |
| --- | --- |
| **商品属性** | SPU维度属性，描述商品基本特征（如材质、风格、适用季节等），根据**末级品类**从品类库动态获取 |
| **销售变体** | SKU维度属性，区分同一商品不同规格（如颜色、尺码、袖型等），根据**一级品类**从品类库动态获取 |
| **SKC** | 一个SPU下一个销售变体值对应的款式，同一值下不同其他变体共用同一个SKC编号 |
| **SKC图** | 对应SKC的商品图片，用于展示该销售变体值的商品效果 |
| **品类库** | 商品运营平台管理的品类分类体系，包含品类层级、商品属性配置（末级品类维度）和销售变体配置（一级品类维度） |
| **大类** | 商品一级分类，如服装、鞋帽、配饰等 |
| **末级品类** | 品类树的最细粒度分类，无子节点的品类。商品属性配置依据末级品类获取 |
| **配置快照** | 商品创建时保存的销售变体配置副本，确保品类库变更不影响已创建商品的销售变体 |
| **方案A** | 品类库有销售变体配置时，使用动态列模式 |
| **方案B** | 品类库无销售变体配置时，使用名称值对模式 |

## 4. 通用规则

### 4.1 品类选择规则

#### 4.1.1 品类层级与可修改性

| 层级 | 说明 | 供应商门户可修改性 | 订单履约平台可修改性 |
| --- | --- | --- | --- |
| 一级品类（大类） | 商品一级分类，如服装、鞋帽、配饰等 | **商品创建后不可修改** | **商品创建后不可修改** |
| 二级品类 | 大类下的细分类别，如服装→上衣、裤装 | 草稿/待完善状态**可修改**，其他状态不可修改 | **可修改** |
| 末级品类 | 品类树的最细粒度分类，无子节点 | 草稿/待完善状态**可修改**，其他状态不可修改 | **可修改** |

#### 4.1.2 品类选择数据源

| 数据来源 | 说明 |
| --- | --- |
| 商品运营平台 | 获取所有**启用状态**的品类数据 |
| 层级结构 | 按一级品类→二级品类→末级品类的树形结构展示 |
| 选择方式 | 级联选择器，从一级逐级展开到末级 |

#### 4.1.3 品类修改后的属性处理

当编辑商品时修改末级品类，系统按以下规则处理：

| 场景 | 处理规则 |
| --- | --- |
| 新品类有原品类不存在的属性 | 新增属性字段，编辑时显示为空，保存时按必填设置校验 |
| 原品类有新品类不存在的属性 | 删除该属性数据 |
| 两品类共有属性 | 保留原有属性值 |

#### 4.1.4 品类选择业务规则

| 编号 | 规则类型 | 规则描述 |
| --- | --- | --- |
| C1 | 约束 | **商品创建成功后，一级品类不可修改** |
| C1.1 | 约束 | 供应商门户编辑商品：草稿/待完善状态可修改二级、末级品类；已选品等其他状态品类不可修改 |
| C1.2 | 约束 | 货品池/待同步商品列表编辑时，可修改二级品类和末级品类，但不可修改一级品类 |
| C2 | 触发条件 | 创建商品时，选择一级品类后动态渲染销售变体配置，选择末级品类后动态渲染商品属性配置 |
| C3 | 约束 | 销售变体配置依据一级品类从商品运营平台动态获取，商品属性配置依据末级品类从商品运营平台动态获取 |

### 4.2 配置快照机制

> ⚠️ **重要设计原则**：**销售变体使用配置快照，商品属性不使用配置快照。**

| 配置类型 | 是否使用快照 | 说明 |
| --- | --- | --- |
| 销售变体配置 | ✅ 使用 | 商品创建时保存销售变体配置快照，品类库变更不影响已创建商品 |
| 商品属性配置 | ❌ 不使用 | 始终使用品类库最新配置，编辑时实时获取 |

**配置快照规则**：

| 编号 | 规则描述 |
| --- | --- |
| S13 | 商品创建时，系统保存该一级品类当时的销售变体配置快照 |
| S14 | 编辑商品销售变体时，使用商品绑定的配置快照，而非品类库最新配置 |
| S15 | 新增SKU时，使用商品绑定的配置快照，销售变体字段与创建时一致 |
| S16 | 品类库销售变体配置变更仅影响**新创建的商品**，已创建商品不受影响 |
| S17 | **商品属性不使用配置快照**，编辑时使用品类库最新配置 |

### 4.3 SKU属性拼接规则

> 💡 本规则适用于所有需要展示SKU属性的页面，原来前端固定使用"颜色/尺码"拼接或分列显示，现改为根据商品的动态销售变体配置展示。

#### 4.3.1 拼接规则

| 规则项 | 说明 |
| --- | --- |
| 数据来源 | 读取商品绑定的销售变体配置快照 |
| 拼接顺序 | **SKC生成依据字段排在最前面**，其他字段按配置顺序排列 |
| 分隔符 | 使用 `/` 分隔各销售变体值 |
| 字段格式 | `{变体值}`，不显示变体名称 |

#### 4.3.2 拼接示例

| 商品销售变体配置 | SKU销售变体值 | SKC生成依据 | 拼接结果 |
| --- | --- | --- | --- |
| 颜色、尺码 | 颜色=红色，尺码=M | 颜色 | 红色/M |
| 款式、颜色、尺码 | 款式=经典款，颜色=白色，尺码=M | 款式 | 经典款/白色/M |

#### 4.3.3 业务规则

| 编号 | 规则描述 |
| --- | --- |
| P1 | SKU属性拼接：SKC生成依据字段在前，其他字段在后，用 `/` 分隔 |
| P2 | 原来的"颜色"、"尺码"两列合并为"SKU属性"一列 |
| P3 | 查看/详情页根据配置快照动态展示销售变体字段 |
| P4 | 创建弹窗根据一级品类最新配置动态展示 |
| P5 | 若商品无销售变体配置，SKU属性显示为空 |

### 4.4 SKC编号生成规则

#### 4.4.1 编号规则

| 规则项 | 说明 |
| --- | --- |
| 编号格式 | SPU编码 + "-" + 2位递增序号（如 SP001-01、SP001-02） |
| 生成时机 | 创建/编辑商品保存时、批量导入商品时 |
| 生成依据（方案A） | 品类库接口返回 `isSkcGenerateBase=true` 的销售变体字段 |
| 生成依据（方案B） | 默认使用**销售变体名称1**对应的值作为SKC生成依据 |
| 递增规则 | 同一SPU下，按生成依据字段的值去重后，按导入顺序递增编号 |
| 不可变性 | **SKC编号一旦生成，不会重新生成**（即使SKC生成依据字段变更） |

#### 4.4.2 业务规则

| 编号 | 规则类型 | 规则描述 |
| --- | --- | --- |
| K1 | 计算 | SKC编号格式：{SPU编码}-{2位递增序号}，如 SP001-01 |
| K2 | 计算 | 方案A：SKC生成依据字段从品类库接口获取（isSkcGenerateBase=true的字段） |
| K3 | 约束 | 每个一级品类仅有一个销售变体字段被标记为SKC生成依据（方案A） |
| K4 | 计算 | 同一SKC生成依据字段值下的不同SKU共用同一个SKC编号 |
| K5 | 计算 | SKC编号按导入顺序递增，相同值复用已有编号 |
| K6 | 约束 | **SKC编号一旦生成，不会重新生成** |
| K7 | 计算 | **数据库需存储SKC生成依据字段名称，作为商品销售变体配置快照的一部分** |
| K8 | 计算 | **方案B：默认使用销售变体名称1对应的值作为SKC生成依据** |

### 4.5 SKC图显示与校验规则

#### 4.5.2 校验触发场景

| 序号 | 平台 | 场景 | 触发条件 |

#### 4.5.3 校验内容

| 校验项 | 校验规则 | 错误提示 |
| --- | --- | --- |
| SKC图必填（方案A） | isSkcImageRequired=true 时，SKC图不可为空 | "SKC图为必填项，请上传" |
| SKC图与值对应 | 校验每个SKC值都有对应的SKC图 | "SKC图不完善：{值}的SKC图未上传" |

#### 4.5.4 方案B商品选品校验

| 场景 | SKC图状态 | 校验结果 |
| --- | --- | --- |
| 未上传任何SKC图 | 空 | ✅ 校验通过 |
| 上传了部分SKC图 | 部分上传 | ❌ 校验失败，提示"SKC图不完善" |
| 上传了全部SKC图 | 完整上传 | ✅ 校验通过 |

**功能概述**：审核缺货申请通过后，系统判断货品池是否存在该商品，根据判断结果执行不同的库存修改逻辑。

**涉及功能点**：

| 功能点 | 改造说明 | 相关规则 |
| --- | --- | --- |
| 货品池商品判断 | 审核通过时判断货品池是否存在该商品 | - |
| 库存联动修改 | 存在则联动修改货品池和待同步商品库存；不存在则仅修改待同步商品库存并自动同步 | D3, D4 |

**处理逻辑**：

| 场景 | 处理逻辑 |
| --- | --- |
| 货品池存在该商品 | 联动修改货品池的商品库存和待同步商品列表的商品库存（原逻辑） |
| 货品池不存在该商品 | 直接修改待同步商品列表的库存，并自动同步到商品运营平台 |

**业务规则**：

| 编号 | 规则类型 | 规则描述 |
| --- | --- | --- |
| D3 | 约束 | 审核缺货申请通过时，先判断货品池是否存在该商品 |
| D4 | 约束 | 若货品池不存在该商品，则直接修改待同步商品库存并自动同步商品运营平台 |

## 7. 商品运营平台接口

### 7.1 品类库查询接口（商品属性）

**接口说明**：根据**末级品类ID**返回对应的商品属性配置。

**接口定义**：

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| categoryId | Long | 末级品类ID |
| categoryName | String | 末级品类名称 |
| attributes | Array | 商品属性列表 |
| └─ attributeName | String | 属性名称（如"材质"、"风格"） |
| └─ isRequired | Boolean | 是否必填 |

**接口返回示例**：

```json
{
  "code": 0,
  "data": {
    "categoryId": 1001,
    "categoryName": "T恤",
    "attributes": [
      { "attributeName": "材质", "isRequired": true },
      { "attributeName": "风格", "isRequired": true },
      { "attributeName": "适用季节", "isRequired": false }
    ]
  }
}
```

### 7.2 品类库接口扩展（销售变体）

**接口说明**：根据**一级品类ID**返回销售变体配置、SKC图必填标识、SKC生成依据字段。

**字段逻辑说明**：

| 字段 | 说明 |
| --- | --- |
| isSkcGenerateBase | 商品运营平台标记某一个销售变体字段作为SKC生成依据，每个一级品类仅有一个字段为true |
| isSkcImageRequired | 只有被标记为SKC生成依据的字段（isSkcGenerateBase=true）才会有此字段，用于控制SKC图是否必填 |

**接口定义**：

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| categoryId | Long | 一级品类ID |
| categoryName | String | 一级品类名称 |
| salesAttributes | Array | 销售变体列表 |
| └─ salesAttributeName | String | 销售变体名称（如"颜色"、"尺码"） |
| └─ isRequired | Boolean | 是否必填 |
| └─ isSkcGenerateBase | Boolean | 是否作为SKC生成依据。每个一级品类仅有一个销售变体字段为true |
| └─ isSkcImageRequired | Boolean | SKC图是否必填。**仅当 isSkcGenerateBase=true 时才有此字段** |

**接口返回示例**：

```json
{
  "code": 0,
  "data": {
    "categoryId": 100,
    "categoryName": "服装",
    "salesAttributes": [
      {
        "salesAttributeName": "颜色",
        "isRequired": true,
        "isSkcGenerateBase": true,
        "isSkcImageRequired": true
      },
      {
        "salesAttributeName": "尺码",
        "isRequired": true,
        "isSkcGenerateBase": false
      }
    ]
  }
}
```

## 9. 异常情况处理方案

### 9.1 商品属性相关异常

| 异常类型 | 异常场景 | 处理方案 |
| --- | --- | --- |
| 接口超时 | 品类库接口响应超过 3 秒 | 展示"商品属性加载中，请稍候"，超时后提示刷新重试 |
| 接口失败 | 品类库接口返回错误码 | 降级：读取本地缓存 + 顶部提示"当前使用缓存的商品属性配置"；无缓存时提示"商品属性加载失败，请联系客服" |
| 末级品类无属性 | 选中的末级品类在品类库中无商品属性配置 | 展示空状态："当前品类暂无商品属性配置"，允许保存商品 |
| 选品校验接口失败 | 货品池选品时品类库接口调用失败 | 使用本地缓存配置进行校验 + 记录告警日志 |

### 9.2 销售变体相关异常

| 异常类型 | 异常场景 | 处理方案 |
| --- | --- | --- |
| 品类无销售变体配置 | 批量导入时选择的一级品类在品类库中未配置销售变体 | 使用备用模板（方案B） |
| 销售变体接口调用失败 | 批量导入时获取品类销售变体配置接口失败 | 提示"获取品类销售变体配置失败，请稍后重试"，提供刷新按钮 |
| 模板列不匹配 | 批量导入时上传的模板列与品类销售变体配置不一致 | 阻断导入，提示"上传的模板与当前品类配置不一致" |
| SKU组合重复 | 同一SPU下存在重复的销售变体组合 | 在预览页面标注错误行，提示具体重复的行号 |
| 配置快照读取失败 | 编辑商品销售变体或新增SKU时读取配置快照失败 | 提示"商品销售变体配置加载失败，请稍后重试" |

### 9.3 SKC图相关异常

| 异常类型 | 异常场景 | 处理方案 |
| --- | --- | --- |
| 品类无SKC生成依据字段 | 品类库接口返回的销售变体均未标记 isSkcGenerateBase=true | 默认使用第一个销售变体字段作为生成依据，记录告警日志 |
| SKC图不完善 | 选品时校验SKC图，SKC图数量不一致或SKC图未对应某个SKC值 | 打上"SKC图不完善"标签，提示具体缺失或未对应的SKC图 |
